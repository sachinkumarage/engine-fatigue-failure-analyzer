## Inputs

range N_min = 1e3 to N_max = 1e6 cycles.

## Hand calculation (σ_a = 400 MPa, σ_m = 150 MPa)

1. B2: σ′_f − σ_m = 1200 − 150 = 1050 MPa.
2. σ_a / (σ′_f − σ_m) = 400 / 1050 = 0.38095238.
3. 1/b = −11.1111111.
4. N_f = ½ · 0.38095238^−11.1111111 = ½ · exp(11.1111111 · 0.96508090)
   = 22696.678850 cycles.
5. 1e3 ≤ N_f ≤ 1e6: no range warning.
