# WE-05 — Column buckling

Equations: C1–C3 (see [buckling.md](../methods/buckling.md)).
Golden test: `tests/golden/test_we05.py`.

## Inputs

Synthetic example, status: assumed. E = 205 GPa, S_y = 750 MPa. Rod-like
column with A = 2.4e-4 m², L = 0.143 m and P = 27763.169641 N (the maximum
compressive rod force of [WE-02](WE-02.md)). The slender case uses
L = 1.5 m and P = 2000 N.

## Hand calculation (plane 1)

1. k = √(1.8e-8 / 2.4e-4) = √7.5e-5 = 0.008660254 m.
2. L_e/k = 1.0 · 0.143 / 0.008660254 = 16.512218.
3. C3: (L_e/k)₁ = √(2π² · 205e9 / 750e6) = √5395.3837 = 73.453276.
   16.51 < 73.45, so the Johnson regime applies.
4. C2: S_y² / (4π² E) = 69503.861 Pa; (L_e/k)² = 272.65333;
   σ_cr = 750e6 − 69503.861 · 272.65333 = 731.04954 MPa.
5. P_cr = 731.04954e6 · 2.4e-4 = 175451.89 N; n = 175451.89 / 27763.169641
   = 6.3195915.
