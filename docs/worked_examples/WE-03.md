## Hand calculation (case A)

1. F2: k_a = 4.51 · 900^−0.265 = 4.51 · 0.16486396 = 0.7435364728.
2. F3: k_b = 1.24 · 40^−0.107 = 1.24 · 0.67387537 = 0.8356054543.
3. F5: k_e = 1 − 0.08 · 2.326 = 0.81392.
4. F6: S_e′ = 0.5 · 900 = 450 MPa.
5. F1: S_e = 0.7435364728 · 0.8356054543 · 1 · 1 · 0.81392 · 1 · 450
   = 227.560970 MPa.
6. N2: √ρ = √0.002 = 0.0447213595 m^0.5; q = 1 / (1 + 0.0019 / 0.0447213595)
   = 1 / 1.0424852916 = 0.9592461477.
7. N1: K_f = 1 + 0.9592461477 (2 − 1) = 1.9592461477.
8. Notched stresses: σ_a = 1.9592461477 · 150 = 293.886922 MPa;
   σ_m = 1.9592461477 · 100 = 195.924615 MPa.
9. M1: σ_a/S_e = 1.29146453; σ_m/S_ut = 0.21769402;
   n = 1 / 1.50915855 = 0.66262090.
10. M2: 2 σ_m S_e / (S_ut σ_a) = 0.33712736; (S_ut/σ_m)² = 21.1011933;
    n = ½ · 21.1011933 · 1.29146453 · (−1 + √(1 + 0.33712736²)) = 0.75348153.
11. M3: (σ_a/S_e)² = 1.66788064; (σ_m/S_y)² = 0.06824259;
    n = √(1 / 1.73612322) = 0.75894399.
12. M4: n_y = 750 / (293.886922 + 195.924615) = 1.53120117.
13. Local-yield check: largest nominal |σ| = 250 MPa; K_f · 250 = 489.8 MPa
    < S_y = 750 MPa, so no warning.
