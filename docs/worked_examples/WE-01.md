## Hand calculation at θ = 45°

1. K1: r = 0.086 / 2 = 0.043 m; λ = 0.043 / 0.143 = 0.3006993007;
   ω = 2π · 6000 / 60 = 628.3185307 rad/s.
2. K2: λ sin θ = 0.3006993007 · 0.7071067812 = 0.2126265146.
   x = 0.043 (1 − 0.7071067812) + 0.143 [1 − √(1 − 0.2126265146²)]
   = 0.0125944084 + 0.0032699030 = 0.0158643114 m.
3. K3: r ω² = 0.043 · 394784.176 = 16975.71957 m/s².
   cos 2θ = cos 90° = 0, so a_p = 16975.71957 · 0.7071067812 = 12003.64642 m/s².
4. K4: β = arcsin(0.2126265146) = 0.2142621565 rad = 12.27631728°.
5. L2: m_rod,A = 0.55 · 0.040 / 0.143 = 0.1538461538 kg;
   m_rec = 0.40 + 0.10 + 0.03 + 0.1538461538 = 0.6838461538 kg;
   m_rot = 0.55 − 0.1538461538 = 0.3961538462 kg.
6. L3: F_i = −0.6838461538 · 12003.64642 = −8208.647439 N
   (directed away from the crank).
7. L7: F_c = 0.3961538462 · 0.043 · 394784.176 = 6724.996599 N.

## Exact acceleration (K3e) and series deviation

Grid: integer degrees 0..359, n = 6000 rpm.

At θ = 90°: sin 2θ = 0 and cos 2θ = −1, so
a_exact = −r ω² λ / √(1 − λ²) = −16975.71957 · 0.3006993007 / 0.9537231
= −5352.296646 m/s², and the series value is −5104.587004 m/s². The
difference r ω² λ (1/√(1 − λ²) − 1) = 247.709642 m/s².
